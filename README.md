# НЕДВИЖИМОСТЬ БЕЛАРУСИ — Railway

Сайт агентства недвижимости «Загородный дом и Недвижимость бел» (УНП 193630299, лицензия Минюста № 02240/452 от 10.11.2022): квартиры и коммерческая недвижимость в Минске, Минском районе и областных центрах. Русский язык, мобильная версия, светлая и тёмная тема. только объекты агентства (сейчас 16 с фотографиями: 1 в продаже, 15 сняты с продажи); демонстрационные объекты удалены, 6 риелторов, заявки сохраняются в SQLite, уведомление менеджеру — в Telegram (необязательно). Зависимостей npm нет.

## Что внутри

- `cloud.mjs` — запуск на сервере (Railway). `server.mjs` — сам сервер; `node server.mjs` — локальный просмотр на http://127.0.0.1:4300.
- `app/` — сайт: `index.html`, `style.css`, `app.js`, шрифты в `fonts/`, фото в `images/`, страница заявок `admin.html`.
- `app/data.json` — **все объекты, риелторы, телефоны, адрес, реквизиты и курс BYN в одном файле.** Правьте его, затем `npm run check-data`.
- `scripts/backup.mjs` — резервные копии базы, `scripts/data.mjs` — экспорт заявок и проверка базы, `scripts/validate-data.mjs` — проверка `data.json`.
- `tests/` — проверки кода (`npm test`).

## Развернуть

1. Создайте **приватный** GitHub-репозиторий и загрузите СОДЕРЖИМОЕ этой папки в корень (в корне должны лежать `package.json`, `Dockerfile`, `cloud.mjs`, `app/`). Не загружайте `.env`, базы и токены.
2. Railway → New Project → Deploy from GitHub repo → нужный репозиторий. Railway возьмёт `Dockerfile` (Node.js 24, команда `node cloud.mjs`) и `railway.json` (healthcheck `/api/health`). Если код лежит в подпапке, укажите её как Root Directory.
3. ДО первого полноценного запуска добавьте Volume и смонтируйте его в `/data`. Без него заявки пропадут при следующем развёртывании. Используйте один экземпляр сервиса (одна SQLite-база).
4. Settings → Networking → Generate Domain (или подключите свой домен). Приложение слушает `0.0.0.0` и порт `PORT`, который даёт Railway.
5. Variables (значения — только в Railway, не в GitHub):
   - `NBEL_PUBLIC_ORIGIN=https://ВАШ-АДРЕС` — без слеша в конце. Без неё каталог работает, но форма заявок отвечает «Приём заявок ещё не настроен».
   - `NBEL_ADMIN_TOKEN` — длинный случайный ключ (от 24 символов) для страницы `https://ВАШ-АДРЕС/admin`.
   - `NBEL_BACKUPS_ENABLED=true` — ежедневные проверенные копии базы в `/data/backups`.
   - `NBEL_TELEGRAM_BOT_TOKEN` и `NBEL_TELEGRAM_CHAT_ID` — уведомления о заявках (см. ниже). Задаются только парой.
   - `NBEL_ALLOW_INDEXING=true` — открыть сайт для поисковиков. До запуска не включайте: по умолчанию сайт закрыт от индексации.
   - `NBEL_PREVIEW_KEY` — необязательно: 32–128 URL-safe символов, тогда сайт открывается только по ссылке `https://ВАШ-АДРЕС/?preview=КЛЮЧ`.
6. Примените переменные (Deploy). В Deploy Logs должно быть: `NBEL web service is listening. Manager delivery: Telegram. Lead form: on.`
7. Проверьте главную, каталог, фильтры, карточку объекта, избранное, мобильную версию. Отправьте одну заявку с пометкой ТЕСТ, найдите её на `/admin`, сделайте Redeploy и убедитесь, что заявка сохранилась.

## Telegram-бот и Mini App

Второй сервис Railway — `bot/worker.mjs` (Dockerfile.bot, railway.bot.json): отвечает на /start приветствием и кнопкой «Открыть каталог», ставит кнопку меню. Переменные и порядок запуска — в `RAILWAY-VARIABLES.txt`. Не запускайте два процесса, получающих обновления одного бота.

Сайт подключён к боту, указанному в `app/data.json` → `site.bot` (сейчас `Rental109_bot`). На сайте появляется ссылка «Каталог в Telegram-боте», а при открытии из Telegram сайт работает как Mini App (разворачивается на весь экран). Сменить бота: `node scripts/set-bot.mjs ИмяБота`. Тексты и картинка для @BotFather — в папке `telegram/`.

## Уведомления в Telegram

1. В @BotFather: `/newbot` → получите токен. Это отдельный бот только для уведомлений; не используйте токен бота AUREVON.
2. Создайте группу для риелторов, добавьте туда бота и напишите в группе любое сообщение (или напишите боту `/start` в личку).
3. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates` и возьмите `chat.id` (у групп он отрицательный, например `-1001234567890`).
4. Задайте `NBEL_TELEGRAM_BOT_TOKEN` и `NBEL_TELEGRAM_CHAT_ID` в Variables.

Заявка сначала сохраняется в базу, потом отправляется в Telegram. Если Telegram недоступен, заявка не теряется: сервер повторяет отправку каждые 5 минут (до 5 попыток за 48 часов), статус видно на `/admin`. Бот только отправляет сообщения, polling и webhook не используются, поэтому он не конфликтует с другими ботами.

## Как менять объекты и фото

1. Откройте `app/data.json`. Каждый объект — блок в `listings`: `id` (PR-0001), `deal` (`sale`/`rent`), `city`, `district`, `address`, `metro`, `rooms` (0 = студия), `area`, `kitchen`, `floor`, `floors`, `year`, `house`, `renovation`, `priceUsd`, `priceByn` (необязательно: точная цена в рублях из объявления; без неё сайт пересчитывает по курсу `bynPerUsd`), `agent` (id риелтора), `description`, `amenities`, `tags`, `pets` (для аренды), `photos`.
   Загородный дом: `"category": "house"` и `type` — Дом, Коттедж, Дача, Таунхаус или Часть дома; `rooms` — число комнат, `floors` — этажность, `livingArea` — жилая площадь, `landSotka` — участок. Для региона укажите `city`: «Минский р-н» или область («Минская обл.», «Витебская обл.» и т. д.), а в `district` — район и деревню.
   Коммерческая недвижимость: добавьте `"category": "commercial"` и `type` — Офис, Склад, Торговое помещение, Здание, Помещение свободного назначения или Готовый бизнес. Для неё `rooms` — число помещений, `kitchen` не нужен, `landSotka` — участок в сотках (необязательно).
2. Фото положите в `app/images/` и перечислите в `photos`: `["images/pr-0001-1.webp", ...]`. Пока фото нет — показывается иллюстрация.
3. Проверьте: `npm run check-data` (или `node scripts/validate-data.mjs`). Ошибки описаны по-русски. Сборка Docker тоже не пройдёт с ошибочным `data.json`, поэтому сломанный каталог не попадёт на сайт.
4. Закоммитьте в GitHub — Railway развернёт новую версию автоматически.

Название, юр. лицо, УНП, лицензия, страховое свидетельство, адрес офиса, телефон, Telegram-канал, e-mail и часы работы (последние два необязательны: пустая строка скрывает строку на сайте) и курс BYN — в разделе `site` того же файла.

Объект, снятый с продажи, остаётся в общем каталоге с пометкой «Снято с продажи» и показывается после актуальных: `"status": "withdrawn"`. Чтобы снова выставить его на продажу, удалите это поле или поставьте `"active"`. Порядок объектов в каталоге — порядок в `data.json`. Риелтор с `"team": false` (например «Отдел продаж») не показывается в разделе «Наши риелторы», но принимает звонки по своим объектам.

## Хранение и резервные копии

SQLite: `/data/leads.sqlite`, содержит имена и телефоны. Доступ к Volume — только у уполномоченных администраторов. В логи контакты не выводятся. Подробности, восстановление и перечень до запуска — `LAUNCH-READINESS.md`.

Команды (Railway → сервис → Shell, или локально с `NBEL_DATA_DIR`):
`node scripts/data.mjs export --csv` — выгрузка заявок, `node scripts/data.mjs backup` — копия сейчас, `node scripts/data.mjs check` — проверка базы.

## Ограничения и проверка

Демонстрационные объекты, телефоны, УНП и реквизиты нужно заменить на реальные. Онлайн-оплаты нет. Избранное хранится в браузере посетителя. Курс BYN задаётся вручную.

Проверка кода: Node.js 24 → `npm test`. Тесты используют временные базы и вымышленные контакты, Telegram не вызывают. Сборку Docker и работу на Railway нужно подтвердить после подключения — локальные тесты не являются отчётом облачного запуска.

Официальный старт Railway: https://docs.railway.com/quick-start
