НЕДВИЖИМОСТЬ БЕЛАРУСИ — ИНСТРУКЦИЯ ПО ЗАГРУЗКЕ В GITHUB И ЗАПУСКУ НА RAILWAY

1. ЧТО ЭТО ЗА АРХИВ
NBEL-deploy-package — чистая сборка сайта для переноса кода. Распаковать перед загрузкой в репозиторий. Сам ZIP не является форматом запуска Railway.
Внутри нет баз заявок, токенов и закрытых настроек. Объекты, телефоны и реквизиты — демонстрационные, их нужно заменить в app/data.json.

2. GITHUB
Создать ПРИВАТНЫЙ репозиторий, например NBEL-SITE. Загрузить СОДЕРЖИМОЕ распакованной папки в корень: package.json, Dockerfile, railway.json, cloud.mjs, server.mjs, app/, scripts/, tests/ и файлы .dockerignore, .env.example, .gitignore.
Файлы, начинающиеся с точки, скрыты в некоторых системах — проверить, что они загружены. Не публиковать .env, токены и базы.
Через сайт GitHub: Add file → Upload files → перетащить содержимое папки → Commit changes.

3. RAILWAY
New Project → Deploy from GitHub repo → NBEL-SITE. Один сервис, один экземпляр.
Сервис → Settings → Volumes (или правый клик по сервису → Attach Volume) → Mount path: /data. Сделать это ДО отправки реальных заявок.
Settings → Networking → Generate Domain. Скопировать адрес вида https://….up.railway.app.
Variables: NBEL_PUBLIC_ORIGIN, NBEL_ADMIN_TOKEN, NBEL_BACKUPS_ENABLED=true, при желании NBEL_TELEGRAM_BOT_TOKEN и NBEL_TELEGRAM_CHAT_ID. Описание — README.md.
Применить изменения и дождаться зелёного статуса (healthcheck /api/health).

4. ПРОВЕРКА ПОСЛЕ ЗАПУСКА
Открыть адрес на компьютере и телефоне. Проверить главную, поиск, фильтры, карточку объекта, избранное, калькулятор, тёмную тему.
Отправить по одной заявке с пометкой ТЕСТ: «Записаться на просмотр» и «Заявка собственника». Проверить сообщение в Telegram (если настроен).
Открыть https://АДРЕС/admin, ввести NBEL_ADMIN_TOKEN, найти обе заявки. Сделать Redeploy и убедиться, что заявки остались.
В Deploy Logs через минуту после запуска: «NBEL backup verified».

5. СВОЙ ДОМЕН
Railway → Settings → Networking → Custom Domain → добавить DNS-запись у регистратора. После подключения изменить NBEL_PUBLIC_ORIGIN на новый адрес (https://ВАШ-ДОМЕН.by, без слеша). Иначе форма заявок будет отклоняться.

6. ОБНОВЛЕНИЯ
Изменения объектов и текстов — через GitHub (app/data.json, app/index.html). Railway разворачивает каждый коммит в основную ветку автоматически.
Перед коммитом: npm run check-data и npm test на Node >=24.13.0 и <25.

7. ДРУГОЙ ХОСТИНГ
Нужен Node 24 или Docker, постоянный диск для /data и HTTPS. Статический или PHP-хостинг эту сборку без адаптации не запустит: каталог откроется, но заявки сохраняться не будут.
