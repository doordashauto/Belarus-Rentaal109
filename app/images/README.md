# Фотографии объектов

Положите сюда фотографии и перечислите их в `app/data.json` в поле `photos` нужного объекта, по порядку показа:

```json
"photos": ["images/pr-0001-1.webp", "images/pr-0001-2.webp"]
```

Имена файлов: латиница, цифры, `-` и `_`; форматы webp, jpg, jpeg, png, avif. Рекомендуемый размер — 1600 px по длинной стороне, до 300 КБ на файл.
Сервер отдаёт только файлы, указанные в `data.json`. Пока у объекта нет фото, сайт показывает иллюстрацию.
Используйте только фото, на которые у агентства есть права (собственная съёмка или письменное разрешение собственника).
